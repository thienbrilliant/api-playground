# Changelog

All notable changes to API Playground are documented here.

The project follows a lightweight semantic versioning approach for user-facing releases.

## [1.0.0] - 2026-09-12

### Added

- Browser-native HTTP client for GET, POST, PUT, PATCH, and DELETE requests.
- Query parameter and request header editors with per-row enable/disable controls.
- JSON request body validation, formatting, and copy support.
- Cancelable requests with timeout handling.
- Response status, timing, size, headers, and body inspection.
- Collapsible JSON response tree with text fallback.
- Browser-local request history.
- Light and dark themes.
- Responsive desktop, tablet, and mobile layout.
- Keyboard shortcut support with `Ctrl/Cmd + Enter`.
- Unit, component, and Playwright end-to-end coverage.
- GitHub Actions quality checks and source-release documentation.
